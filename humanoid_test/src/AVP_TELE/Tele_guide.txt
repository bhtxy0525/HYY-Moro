# AVP 遥操作流程

## 1. 连接 AVP

AVP 和机器人电脑连接同一网络，戴好 AVP，打开 Tracking Streamer。

确认 Python 文件中的 `AVP_IP_CANDIDATES` 包含 AVP 当前 IP。

## 2. 启动 Python

```bash
conda activate avp
cd ~/Documents/humanoid_test/src/AVP_TELE
python VisionProCppCommunication.py
```

等待终端提示 `[AVP] 已连接：…`。

## 3. 启动机器人程序

运行调用 `HumanoidTeleoperationDemo()` 的 C++ 程序。

**机器人会先运动到预设初始位置，确保周围空间无障碍。**

## 4. 开始遥操作

先松开双手，再捏合：

- 左手捏合：控制左臂。
- 右手捏合：控制右臂。
- 松开某只手：保持该侧最后的末端目标。
- 再次捏合：以当前手的位置和姿态为新起点继续控制。

**回正规则（使用 `&&` 版本）：**双手都捏合且检测到目标运动时开启回正；双手静止或任意一只手松开后，平滑关闭回正。另一只手仍可正常控制。

## 5. 摘戴与重连

摘下 AVP 导致断流后，C++ 结束本次遥操作，Python 自动尝试重连。

重新戴好并开启串流，等待提示“已连接”，再手动启动 C++ 遥操作程序；机器人会重新执行初始化。

## 6. 结束操作

在 Python 终端按 `Ctrl+C`。C++ 检测到断流后，关闭左右臂及躯干三组伺服，结束遥操作。

**需要立即停止机器人时，按硬件急停。**
